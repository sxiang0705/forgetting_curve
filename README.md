# 遺忘曲線提醒工具 (Forgetting Curve Reminder Tool) 🧠

這是一款基於 Python (Tkinter) 打造的桌面端 **學習/任務管理與提醒工具**。透過引入「艾賓浩斯遺忘曲線 (Ebbinghaus Forgetting Curve)」的概念，幫助您自動排程複習時間，最大化學習成效；並結合了美觀直覺的介面與豐富的圖表報表功能。

## ✨ 核心特色 (Features)

* **任務與分類管理**：輕鬆新增、編輯、刪除任務，並自訂分類（如：英文單字、程式技能等）與難易度。
* **智慧遺忘曲線排程**：除了手動輸入提醒時間，更提供自動「遺忘曲線」模式，只需設定複習次數，系統為您自動推算最佳複習間隔（例如：1, 3, 7, 14, 30天等）。
* **背景自動提醒**：程式在背景每 30 秒自動檢查到期提醒，時間一到立即彈出視窗通知！
* **視覺化互動日曆**：右側面板包含彩色標籤日曆，不同顏色代表該日未完成任務的數量（淺紅/中紅/深紅）。點擊日期即可查看、完成或推延當日任務。
* **學習進度與報表寄送**：
  * 自動計算任務完成百分比（Progress %）。
  * 支援產生「本週完成率圓餅圖」、「本月完成率圓餅圖」、「近四週完成度長條圖」。
  * 支援將圖表報表作為附件，自動寄送到指定的 Email 信箱。
* **CSV 匯入與匯出**：完美解決資料備份與還原需求，輕鬆匯出您的任務庫！
* **個人化動態背景**：支援一鍵更換專屬桌布，每次打開工具都能擁有好心情。UI 介面（V6版本）更導入微軟正黑體、現代化扁平框線與光標回饋設計。

## 🛠️ 環境與依賴套件 (Prerequisites)

本專案使用 Python 3 開發，請確保您已安裝 Python 3.8 或以上版本。在使用前，需安裝以下第三方套件：

```bash
pip install tkcalendar Pillow matplotlib
```

*(其他如 `tkinter`, `sqlite3`, `datetime`, `os`, `hashlib`, `csv`, `smtplib` 為 Python 內建標準庫)*

## 🚀 執行與操作教學 (How to Use)

### 1. 啟動程式

**🔑 方式一：使用獨立執行檔 (.exe)（推薦，免安裝環境）**
如果在專案中（或是 `dist/` 資料夾內）有打包好的 `.exe` 執行檔（例如 `ForgettingCurve_V6.exe`），只要對著該檔案 **雙擊左鍵 (Double-click)** 即可直接開啟使用，無需預先安裝 Python 任何環境及套件！

**🔑 方式二：使用 Python 原始碼執行**
將專案 Clone 或下載到本地端資料夾後，確保安裝好相關依賴套件，接著在終端機或命令提示字元中執行：

```bash
python curve.py
```
*(程式啟動後，會在此目錄下自動產生 `reminder.db` 用以儲存任務資料，並自動建立 `backgrounds/` 資料夾)*

### 2. 新增與排程任務
1. 設定右下方表單中的 **任務名稱**、**分類** 以及 **難度**。
2. 選擇 **提醒模式**：
   * **手動輸入**：您可以自訂每一個要被提醒的具體時間點。
   * **遺忘曲線**：選擇「開始日期、時間」以及「複習次數」，系統將自動產生一系列間隔漸遠的提醒時間。
3. 點選 **「＋ 新增任務並設定提醒」**。

### 3. 查看提醒與任務狀態
* 當提醒時間到達時，系統會從背景彈出通知視窗。點選「我已複習」可將該次提醒消除。
* 點選右方月曆中標有顏色的日期，可查看當日的詳細任務內容，並支援**「完成」**或**「推延」**（推延會自動將所有未完成的任務向後順延一天）。

### 4. 變更個人化背景
1. 點選右側功能列的 **「🖼 個人化背景」** 按鈕。
2. 您可以上傳新的背景圖片（支援 `.png`, `.jpg`, `.jpeg` 等格式）。
3. 選擇圖片後，系統將自動套用至左側任務列表，帶來絕佳體驗！

### 5. 匯入/匯出與報表寄送
* 想要備份資料？點選 **「📤 匯出」** 按鈕，將資料庫匯出為 CSV。
* 想要檢查進度？點擊下方的 **「📊 本週/本月完成率」** 按鈕看長條圖/圓餅圖。並可透過 **「寄送所選報告」**，將進度圖表自動發布到您的 Email。

## 📂 專案結構
* `curve.py`: 應用程式主執行檔與圖形介面。
* `reminder.db`: (自動執行後產生) 儲存任務資料的 SQLite 資料庫。
* `backgrounds/`: (自動新增背景後產生) 儲存個人化背景的圖庫資料夾。
* `update_record/`: 包含各版本更新的詳細功能紀錄。
