# Renew Curve v8 Roadmap

這份文件整理後續開發方向。原則是先穩定 v8 架構與使用流程，再逐步補回舊版功能。

## 優先處理

1. 背景與貼圖素材管理
   - 新增刪除背景圖片的 UI。
   - 新增刪除貼圖素材的 UI。
   - 刪除素材時同步更新 SQLite 素材紀錄。
   - 避免刪除目前仍被啟用的素材後造成畫面錯誤。

2. 提醒彈出視窗
   - 移植舊版背景提醒彈窗。
   - 優化彈窗 UI，讓提醒內容、完成、稍後提醒與關閉操作更清楚。
   - 補上勿擾或低干擾模式的設計。

3. 提醒系統優化
   - 檢查常駐提醒流程。
   - 補上背景執行或定時檢查策略。
   - 確認 Windows 桌面使用情境下的提醒可靠性。

## 暫緩處理

- 資料庫 schema 先不大改。
- 若要新增欄位或改 schema，先補 migration 設計與備份驗證。
- 打包 `.exe` 前，先確定提醒流程與資料備份流程穩定。

## 後續可規劃

- 任務編輯與刪除。
- 單筆提醒編輯。
- 更完整的報表與圖表。
- Email 或其他外部通知。
- 正式 Windows 打包流程。
- GitHub Releases 與版本標籤。
