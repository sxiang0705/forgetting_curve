# Renew Curve v8 現代化 GUI 設計規格

日期：2026-05-07  
狀態：待使用者審閱  
語言：繁體中文

## 目標

這次改版的核心目標是讓 Renew Curve v8 成為可以承接舊版 CSV 資料、日常使用更直覺、且具備高度個人化能力的新版本。

成功標準：

- 舊版匯出的 CSV 可以順利匯入新版，任務、提醒、分類、備註與完成狀態都能保留。
- 主畫面以「今天要處理的任務」為中心，不再被統計或資料管理功能干擾。
- 使用者可以清楚完成、推延、查看備註、查看未來任務、分類檢視所有任務。
- 新增任務時能明確選擇「遺忘曲線」或「手動輸入」兩種排程方式，新增前可預覽提醒日期。
- 報表與資料管理集中在獨立視窗，資料匯入匯出不放在主畫面。
- 個人化是全域主題系統，會套用到主畫面、新增任務、報表資料與排程說明；貼圖裝飾預設在主畫面最明顯，功能視窗低密度顯示。
- 所有彈跳視窗不播放提示音。

## 主畫面

主畫面第一優先顯示「今天任務」。左側月曆點到哪一天，中間任務區就顯示該日期的任務；右上或月曆旁提供「回到今天」按鈕。

今天任務區：

- 顯示任務名稱、分類、時間、第幾次複習、完整備註。
- 每筆任務有 `完成` 與 `推延` 兩個按鈕。
- `完成` 與 `推延` 都使用白底灰框樣式，避免綠色/橘色造成過度強烈的視覺分裂。
- 任務很多時，今天任務區本身有內部捲軸，不把所有任務區往下推太遠。

左側月曆：

- 支援上一個月、下一個月。
- 日期格顯示當日任務數量。
- 日期依任務數量變色，例如 1-2、3-4、5-6、7+。
- 點選日期後，中間主區切換成該日期任務。

左側未來任務：

- 從「接下來 7 天」改為「接下來 3 天」。
- 每一天直接列出該日任務名稱與數量，不再重複顯示「複習任務」。
- 這區用於快速知道近期壓力，而不是取代主畫面的日期切換。

所有任務區：

- 固定在主畫面下方。
- 支援分類檢視，分類來自資料庫中既有任務分類。
- 任務很多時此區塊內部捲動。
- 顯示任務名稱、備註摘要、分類、下一次提醒、進度。

## 完成與推延邏輯

完成：

- 只完成目前這一次提醒。
- 不會整批改動後續提醒日期。
- 完成後該任務從今日清單移除或標示為已完成，下一次提醒仍依原本排程存在。

推延：

- 預設推延只移動目前這一筆提醒。
- 預設選項包含 10 分鐘、1 小時、明天同時間。
- 支援「整批推延」作為進階選項；啟用後，該任務尚未完成的未來提醒會一起往後移動相同時間。
- 推延後要明確顯示會影響幾筆提醒，避免使用者誤會。

排程說明視窗需說明：

- 新增任務時如何產生提醒。
- 完成只完成當前提醒。
- 推延預設只影響當前提醒。
- 整批推延會一起移動後續未完成提醒。

## 新增任務

新增任務使用獨立視窗，視窗本身可捲動。按下 `新增任務` 成功後，視窗關閉並刷新主畫面。

欄位：

- 任務名稱。
- 分類：可從既有分類下拉選擇，也可輸入新分類。
- 難度。
- 備註。
- 排程制定方式。
- 開始時間。
- 複習次數。
- 複習日期預覽。

排程制定方式有兩種：

1. 遺忘曲線
   - 使用者選擇開始時間與複習次數。
   - 系統依預設間隔自動產生日期。
   - 預設間隔可使用 1、3、7、14、30 天；若複習次數超過預設長度，後續依既有邏輯延伸。

2. 手動輸入
   - 使用者仍需選擇複習次數。
   - 系統依複習次數產生對應數量的日期時間欄位。
   - 每一次提醒時間由使用者自行輸入。

預覽：

- 新增前右側顯示所有會產生的提醒日期。
- 遺忘曲線模式顯示「開始後幾天」。
- 手動輸入模式顯示使用者輸入的日期時間。

## 報表與資料

報表 / 資料使用獨立視窗，不放在主畫面。

視窗內容：

- 左側顯示統計。
- 右側顯示資料操作。
- 右上只保留關閉 `×`，不放多餘的 `總覽 / 資料操作` 分頁按鈕。

統計：

- 全部任務。
- 今日任務。
- 未完成提醒。
- 已完成提醒。
- 前 7 天總完成率。
- 總完成率。

前 7 天總完成率：

- 計算方式為前 7 天所有到期提醒加總後，用完成數 / 應完成數得到單一完成率。
- 可在下方顯示每日完成數作為輔助資訊。
- 這個數字用來判斷最近一週整體複習是否穩定。

資料操作只保留三個入口：

1. 匯入舊版 CSV
   - 檔案類型：`.csv`。
   - 用途：舊版資料轉新版。
   - 系統讀取 task 與 reminder，並以提醒完成數重新計算進度，不完全相信 CSV 裡 task 的 progress 欄位。

2. 匯出完整資料
   - 檔案類型：`.zip`。
   - 用途：新版主要備份格式。
   - ZIP 內容包含 SQLite 資料庫、manifest、背景圖片、貼圖、個人化設定與備份說明。

3. 匯入完整資料
   - 檔案類型：`.zip`。
   - 用途：還原新版完整資料。
   - 系統會先解壓縮並檢查內容，確認可讀取後才替換目前資料。

錯誤處理：

- 匯入 CSV 時若欄位不符，要顯示明確錯誤，不覆蓋目前資料。
- 匯入 ZIP 時若缺少必要檔案、資料庫不可讀、manifest 不合法，不能覆蓋目前資料。
- 匯入完整資料前需備份目前資料，避免失敗時無法復原。

## 個人化

個人化分成「介面風格」與「我的素材」，避免使用者誤會主題等於背景圖片。

介面風格：

- 控制整體氣質，例如卡片顏色、按鈕樣式、月曆色彩、背景遮罩預設、貼圖顯示規則。
- 不直接替換或刪除使用者的背景圖片與貼圖。
- 預設主題可包含：
  - 療癒粉彩。
  - 清爽雪山。
  - 深色專注。
  - 自訂風格。

我的素材：背景圖片

- 支援上傳背景圖片。
- 背景庫可選用、刪除。
- 支援背景透明遮罩、背景模糊、背景暗化。
- 換主題不會刪除或覆蓋背景圖片。

我的素材：小貼圖

- 支援上傳 PNG / GIF 貼圖。
- 貼圖庫可選用、不使用、刪除。
- 支援顯示位置：
  - 卡片右上。
  - 標題前。
  - 區塊空白角落。
  - 隨機安全區。
- 支援顯示密度：少、普通、多。
- 貼圖不能遮住任務文字、按鈕、輸入欄位或統計資料。

全域套用規則：

- 主題色、按鈕樣式、卡片樣式、背景遮罩套用到主畫面、新增任務、報表資料、排程說明。
- 貼圖預設在主畫面最明顯。
- 新增任務與報表資料等功能視窗預設低密度貼圖，只出現在標題或邊角。
- 排程說明可完全關閉貼圖，以閱讀清楚為優先。
- 使用者可以選擇是否把貼圖擴展到所有視窗。

完整資料 ZIP 必須包含個人化設定與素材，讓備份還原後可以保留使用者的背景、貼圖與主題選擇。

## 資料承接

舊版 CSV 是跨版本資料交換格式，新版必須保留匯入能力。

CSV 匯入要求：

- 支援舊版欄位：`record_type`、`id`、`task_id`、`title`、`category`、`difficulty`、`notes`、`reminder_method`、`start_time`、`is_completed`、`progress_percent`、`remind_time`、`reminded`。
- `record_type = task` 轉為任務。
- `record_type = reminder` 轉為提醒。
- 備註要完整保留，不能只顯示摘要。
- 分類與難度完整保留。
- 完成狀態以 reminder 的完成狀態為準。
- 任務進度由提醒完成數重新計算。

新版資料備份：

- CSV：保留給舊版匯入、新舊交換與簡易備份。
- ZIP：新版主要完整備份與還原格式。

## 視窗與聲音

- 所有彈跳視窗不播放提示音。
- 新增任務、報表資料、排程說明、個人化都要有清楚的 `×` 或回到主畫面的方式。
- 視窗內容超出高度時需提供捲軸。
- 按鈕文字要清楚描述用途，避免只靠圖示。

## 測試重點

- 匯入使用者提供的舊版 CSV 範例後，任務數、提醒數、分類、備註與完成率都正確。
- 今日任務只顯示當日到期提醒。
- 月曆點選日期會切換中間任務區。
- `回到今天` 正常恢復今日任務。
- 所有任務分類篩選正確。
- 完成只完成當前提醒。
- 推延預設只推延當前提醒。
- 整批推延會正確移動後續未完成提醒。
- 新增任務的遺忘曲線模式能產生正確日期。
- 新增任務的手動輸入模式能依複習次數產生對應日期欄位。
- 匯出完整資料 ZIP 後再匯入，可以還原資料庫、設定、背景與貼圖。
- 個人化主題能套用到主畫面、報表、新增任務與排程說明。
- 貼圖不遮住文字、按鈕、輸入欄位或統計資料。
- 視窗不播放提示音。
