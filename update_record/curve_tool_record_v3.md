# 遺忘曲線提醒工具（`curve.py`）更新紀錄（v3）

這版 v3 針對你實際遇到的介面問題與操作習慣做修正：

1. 小螢幕下右側月曆可見（不再被擠掉、也不需要滑輪）
2. 新行程的提醒模式預設為「遺忘曲線」
3. 移除「修改行程」面板；改成在 `task_tree`（左上任務清單）**雙擊**跳出修改彈窗

---

## 1) 右側月曆顯示問題修正

之前左/右用固定寬度 `pack` 排版，較小解析度時右側月曆可能直接被擠到視窗外、也沒有滑動方式能看到。

v3 改為在主視窗用 `ttk.Panedwindow(orient="horizontal")` 分割：
- 左側：任務清單 + 新行程表單
- 右側：月曆

因此在 16 吋副螢幕也會盡量保證月曆區塊可見；同時也不用依賴滑輪才能看見另一側。

---

## 2) 新行程提醒模式預設

新增任務的 `提醒模式`（`new_reminder_mode_var`）預設值改為：
- `遺忘曲線`

清空新行程表單（`clear_new_form()`）時也同步會把預設切回 `遺忘曲線`。

---

## 3) 修改行程 UI 移除，改成雙擊彈窗

v2 的「修改行程」LabelFrame 介面已移除。

操作方式改為：
1. 在左上 `task_tree` 單擊選取任務
2. **雙擊（Double-1）該任務列**
3. 跳出 `修改任務資訊` 彈窗，可編輯：
   - 任務名稱
   - 分類（可自訂）
   - 難度
   - 備註

儲存後會自動：
- 更新 `tasks`
- 重新標色月曆（`tag_calendar_by_category()`）
- 重新載入任務清單（`load_tasks()`）

提醒時間（`reminders`）目前 v3 不做重新排程修改；雙擊彈窗只更新任務資訊本身。

---

## 4) 其他背景

v3 沒有改動你先前新增的 CSV 匯入/匯出、比例進度顯示、以及分類可自訂與動態篩選等功能；這些仍沿用 v2 的行為。
