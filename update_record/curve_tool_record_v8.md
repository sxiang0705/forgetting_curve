# 遺忘曲線提醒工具更新紀錄 v8

v8 是一次以「資料承接優先」為核心的大翻新版本。這個版本開始把舊版 Tkinter 單檔程式整理成 PySide6 現代桌面應用，並建立可測試、可維護的資料層與 CSV 相容層。

## 1. GUI 介面現代化

- 將新版主介面改為 PySide6。
- 將主介面按鈕、表格欄位與主要對話框改為繁體中文。
- 建立三欄式工作區：
  - 左側為主要功能導覽與匯入匯出入口。
  - 中央為任務列表、搜尋欄、新增任務與統計資訊。
  - 右側為日曆與選取日期區塊。
- 建立一致的主題樣式，支援亮色、深色、重點色與緊湊密度設定。
- 新增 `Settings` 對話框，讓使用者能調整個人化偏好。

## 2. 新版資料庫與程式結構

- 新增 `src/renew_curve/` 套件架構，將功能拆分為資料庫、排程、CSV 相容與 GUI 模組。
- 以 SQLite 作為 v8 資料庫，預設使用 `renew_curve_v8.db`。
- 新增 `ReminderRepository`，集中管理任務、提醒、進度與設定資料。
- 補上 transaction 邊界，避免 repository 方法自行提交造成外層交易無法回滾。

## 3. 舊版 CSV 承接

- 新增 `csv_compat.py`，支援讀取舊版匯出的 `.csv`。
- 支援 `replace` 與 `merge` 兩種匯入模式。
- `replace` 匯入會先寫入暫存資料庫，成功後才替換正式資料庫，避免匯入失敗造成原資料消失。
- 匯入時會重新計算任務完成度，避免舊 CSV 的任務完成狀態與提醒資料不一致。
- 匯入 malformed reminder datetime 時會明確報錯，不會默默吞掉壞資料。
- v8 匯出的 CSV 保留舊版欄位格式，方便繼續備份與轉移。

## 4. 個人化設定保留

- 新增主題、重點色、介面密度與預設 snooze 設定。
- 修正 CSV `replace` 匯入時會洗掉設定的問題。
- 現在即使使用 replace 重新匯入舊 CSV，使用者的個人化設定仍會保留。
- 設定寫入跟隨外層 transaction，若同一批資料操作失敗，設定與資料會一起回滾。

## 5. 新增任務流程

- `New task` 對話框現在可以真正建立任務。
- 支援輸入任務名稱、分類、難度、筆記、模式、開始時間與複習次數。
- 使用「遺忘曲線」模式時，會依 1、3、7、14、30、60、90、120、180、365 天的規則自動產生提醒。
- 建立後會立即刷新新版任務表格。

## 6. 下一次提醒操作

- 任務表格的「下一次」欄位會顯示下一筆未完成提醒時間。
- 選取任務後可直接按「完成下一次」，完成目前最早的未完成提醒。
- 完成提醒後會重新計算任務進度；當所有提醒完成時，任務狀態會變成已完成。
- 選取任務後可按「稍後提醒」，依個人化設定中的預設 snooze 選項延後下一筆提醒。

## 7. 測試與品質

- 新增 scheduler 測試，確認遺忘曲線天數、進度百分比與 snooze 邏輯。
- 新增 SQLite repository 測試，保護任務、提醒、進度與 transaction 行為。
- 新增 CSV 匯入匯出測試，保護舊資料遷移與 round-trip 相容性。
- 新增 GUI import smoke test、新增任務測試、完成下一次提醒測試、稍後提醒測試與繁中標籤測試。
- 新增設定測試，確認個人化設定可保存、可回滾，且 replace 匯入不會覆蓋設定。

  - 建立 SQLite repository。
  - 建立 CSV 相容匯入匯出。
  - 建立 PySide6 主視窗。
  - 加入 import/export 對話框與 GUI actions。
  - 加入個人化設定。
  - 修正 CSV replace 保留個人化設定。
  - 補上新版 GUI 新增任務流程。
  - 補上下一次提醒完成、稍後提醒與繁中介面。
